# git-nudge の変更履歴

## 0.1.1 — 2026-11-21

- 修正: `/git-nudge pull` と帯の `p` が、先に行う fetch の失敗を見ていなかった。オフラインや認証切れのとき、古い追跡ブランチを基準に「取り込むものがありません」「取り込みました」と答えていた。fetch に失敗したら取り込まず、そう伝えるようにした。
- 修正: 「前回からの未 push」「前回の未コミット変更」を、件数の一致だけで出していた。push した後に同じ数だけコミットしたときや、同じ数だけ進んだ別のブランチに移ったときにも出ていた。セッションが最初に見たときの HEAD のコミットとブランチ、未コミットの項目が同じ間だけ出すようにした。
- 修正: `/clear`・`/resume`・`/branch` の後、そのセッションで作ったコミットや変更を「前回から」と伝えていた。最初に見た状態を基準に保つようにした。
- 修正: upstream が消えたブランチを push し直しても、次の fetch まで `upstream 消滅` と出し、取り込みを断り、Claude にも「削除済み」と伝えていた。remote 追跡 ref が動いたブランチは、fetch を待たずに外すようにした（同じコミットのまま push し直した場合は、次の fetch まで残る）。
- 修正: `/git-nudge tidy` で消した直後も、帯が「upstream が消えたブランチ N 本」を古い数のまま出していた。消したブランチを数から外すようにした。
- 修正: fetch の途中で `/git-nudge off` を打つと、fetch が終わったときにステータス行が戻り、消えなかった。off の後は表示を消し直し、新しい fetch も始めないようにした。
- 修正: `git version` が1度失敗する（時間切れなど）と、セッションが終わるまで「git が見つかりません」と出て何もしなかった。次の見直しでやり直すようにした。文言は「git を実行できませんでした（入っていないか、応答がありません）」に変えた。
- 修正: `git rev-parse --show-toplevel` の時間切れを「git リポジトリの中ではありません」と扱い、表示と、セッション開始時の基準・Claude に伝えた内容・認証での停止を消していた。時間切れのときは、そのまま保つようにした。
- 修正: `/git-nudge tidy` が、Claude の作業中と `/git-nudge off` の間も動いていた。どちらも断るようにし、確認を待つ間に作業が始まったときも消さないようにした。
- 修正: `x: 閉じる` で隠した項目が、状態が解消して同じ内容でまた起きても出なかった。解消したら、閉じた記録も消すようにした。
- 修正: 片付けの案内（1日1回）が、帯に出ないまま当日分を使い切ることがあった（帯をオフにしている、帯の2行に入らない、帯を描かない環境）。帯に出したときにだけ記録するようにした。日付は UTC ではなく現地の日付にした（日本では9時に日が変わっていた）。
- 変更: `git-nudge.fetchInterval` の上限を 1440 分（1日）にした。超える値は 1440 として扱い、`/git-nudge` の「設定の問題」に出す（タイマーが待てる長さを超える値を防ぐ）。
- 内部: 取り込みと片付けの「Claude の作業中」の判定を、モジュールの変数でも持つようにした。確認を待つ間に始まったターンを、hook が読む `$.state` では見落とすことがあるため。

## 0.1.0 — 2026-10-07

最初の版です。

- 追加: upstream との差（↓↑）、upstream なし・消滅、未コミットの変更、stash、途中の rebase / merge / cherry-pick / revert / bisect、残った `index.lock`、detached HEAD をステータス行に出す。
- 追加: 手を打てることを帯に出す。遅れていて安全なときは `p` で fast-forward（`git merge --ff-only @{u}`）。数字のホットキーは使わない。
- 追加: 状態が変わったときだけ Claude に伝える。指示なしに pull・rebase・push・ブランチの削除をしないよう添える。
- 追加: `/git-nudge tidy` で、upstream が消えた HEAD にマージ済みのブランチを、確認してから `git branch -d` で消す。
- 追加: 設定は `git config` の `git-nudge.*`（enabled / fetchOnStart / fetchInterval / tellClaude / band / stashAgeDays）。
- 追加: fetch と ls-remote は認証の入力や画面を出さない。SSH は、利用者が ssh コマンドを設定していなければ `BatchMode=yes` で動かす。
- 追加: `/git-nudge pull` と帯の `p` は、先に fetch してから取り込む。Claude の作業が途中で始まったら取り込まない。
