# quality-router の変更履歴

## 0.3.1 — 2026-10-07

このリポジトリ（ns-mods）で公開した最初の版です。

- 変更: 本体モデルの守り（会話の相手を上位モデルに戻す）を既定で off にした。`/qr guard on` で有効になる。
- 変更: effort-router を、ユーザー設定に加えて、読み込まれているコマンドの一覧からも検知するようにした（どのスコープで入れても気づく）。検知したら本体の Effort を effort-router に任せ、続ける機能を通知で知らせる。
- 文書: README を、導入・使い方・費用とデータ・仕組みの順に組み直した。effort-router と一緒に使うときの動作を書いた。

## 0.3.0 以前

公開前の版です。主な変更は次のとおりです。

- 0.3: 判定の記録（`~/.claude/quality-router/log/`）、`/qr stats`、`/qr up`・`/qr down` を追加した。
- 0.2: サブエージェントと Workflow の役割を、作業の種類8つと重さの2軸にした。状態表示と `/qr version` に版を出すようにした。
- 0.1: 本体の Effort の振り分け、スキル連動の下限、途中の格上げ、本体モデルの守り、サブエージェントの振り分け、Workflow の点検。
